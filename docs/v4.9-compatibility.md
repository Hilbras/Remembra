## Compatibility decisions

- Existing unversioned HTTP routes remain aliases and retain their route-specific
  response bodies.
- The stable MCP manifest keeps all 13 existing names; no aliases are silently
  introduced.
- `@hilbras/remembra/sdk` and `@hilbras/remembra/providers` are side-effect-free
  subpaths. The package root and `remembra` binary remain the CLI entrypoint.
- Trusted agent context is supplied by the host after authentication. Client
  fields are never treated as identity, and the SDK rejects server-managed
  identity/access fields.
- Provider adapters cannot bypass the bounded provider policy. Existing env
  configuration and fail-open embedding behavior remain unchanged.
- Node support is `>=18.14.1`; the Hono server transitive dependency is pinned
  to patched `1.19.17` for Node 18 compatibility.
