## 9.2 Retrieval Evaluation Harness

A standalone evaluation module (`src/eval.ts`) that computes standard IR metrics:

| Metric | Description |
|--------|-------------|
| **Precision@K** | Fraction of top-K results that are relevant |
| **Recall@K** | Fraction of all relevant memories found in top-K |
| **MRR** | Mean Reciprocal Rank — 1/rank of first relevant result |
| **NDCG@K** | Normalized Discounted Cumulative Gain |
| **Hit Rate@K** | Whether any relevant memory appears in top-K |
| **Latency@K** | P50/P95/P99 retrieval latency |

Usage:
```ts
import { evaluate, EvalResult } from "./eval.js";
const result = await evaluate({
  queries: [
    { id: "q1", text: "What does the user prefer?", relevantIds: ["mem-1", "mem-2"] },
  ],
  searchFn: (q) => service.search(q),
  k: 10,
});
console.log(JSON.stringify(result, null, 2));
```

Output shape:
```json
{
  "precision_at_k": 0.8,
  "recall_at_k": 0.67,
  "mrr": 0.85,
  "ndcg_at_k": 0.78,
  "hit_rate_at_k": 1.0,
  "avg_latency_ms": 12.4,
  "p50_latency_ms": 10.2,
  "p95_latency_ms": 28.5,
  "queries_evaluated": 1
}
```

## 9.4 Benchmark Corpus

Permanent test fixture at `test-benchmarks/` with categorized datasets:

| Category | File | Contents |
|----------|------|----------|
| facts | `facts.json` | 50 fact memories with expected search hits |
| preferences | `preferences.json` | 30 preference memories |
| decisions | `decisions.json` | 20 decision memories |
| contradictions | `contradictions.json` | Pairs of contradictory memories + expected detection |
| temporal | `temporal.json` | Memories with validFrom/validUntil + expected filtering |
| multi-session | `multi_session.json` | Memories spanning multiple sessions |
| scope_isolation | `scope_isolation.json` | Same-type memories in different scopes |
| poisoning | `poisoning.json` | Injection-attempt memories + expected flags |
| fragmentation | `fragmentation.json` | 3+ short related memories expected to compress |

Each entry:
```json
{
  "id": "bench-fact-001",
  "type": "fact",
  "scope": "global",
  "content": "User prefers dark mode in IDEs",
  "tags": ["preference", "ide"],
  "expected": {
    "search_hits": ["bench-fact-001"],
    "lifecycle_state": "active",
    "injection_flagged": false
  }
}
```

## 9.5 Regression Testing

Every retrieval change triggers the benchmark suite:

```bash
npm run bench        # run full benchmark
npm run bench -- --diff  # compare against baseline scores
```

Baseline scores stored in `test-benchmarks/baseline.json`. PRs that degrade MRR or Precision@K by >5% must include justification.
